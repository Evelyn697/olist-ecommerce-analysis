# 业务数据指标字典（Metric Dictionary）

> 本文件定义项目中使用的核心数据指标口径，旨在保证数据一致性、可追溯性。

---

## 口径总则（全指标通用）

| 项目 | 约定 |
|---|---|
| 有效订单 | order_status = 'canceled'和'unavailable'的订单定义为无效订单，其余为有效订单 |
| 物流履约分析对象 | 仅 `order_status = 'delivered'` 且签收时间非空的订单 |
| 延迟口径 | 实际签收时间 > 承诺送达时间，按**自然日**计 |
| 时间基准 | 一律使用订单表时间字段，不使用评价表时间 |
| 已声明局限 | 数据跨越 2016.09–2018.09，2016 年平台处于起步早期，部分月份数据缺失，2018.09为数据集末期，样本偏少。因此，趋势分析从 2017-01 起至2018-08止。 |

---



## 1. 经营与用户域

| 指标名称           | 英文/代码字段       | 业务口径定义                                                 | 计算公式                                                     | 数据源              |
| :----------------- | :------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- | :------------------ |
| **商品交易总额**   | `GMV`               | 统计周期内所有有效订单的商品总金额（含运费，排除取消/不可用） | `SUM(order_total_value)`                                     | `fct_order_summary` |
| **客单价**         | `AOV`               | 每个有效订单的平均贡献金额                                   | `SUM(order_total_value) / COUNT(DISTINCT order_id)`          | `v_orders_enriched` |
| **复购率**         | `Repurchase Rate`   | 统计周期内，下单次数≥2次的客户占总下单客户的比重             | `复购客户数 / 总客户数`                                      | `dim_customers`     |
| **高价值客户占比** | `High-Value User %` | 基于RFM模型，R和M打分均≥4分的客户占比                        | `SUM(CASE WHEN segment IN ('高价值活跃','高价值流失风险') THEN 1 END) / COUNT(*)` | `fct_customer_rfm`  |

## 2. 物流与交付域

| 指标名称               | 英文/代码字段        | 业务口径定义                                                 | 计算公式                             | 数据源             |
| :--------------------- | :------------------- | :----------------------------------------------------------- | :----------------------------------- | :----------------- |
| **交付达成率(准时率)** | `OTIF`               | 实际送达时间早于或等于承诺送达时间的订单占比（分母为已送达订单） | `SUM(is_late = 0) / COUNT(*)`        | `fct_orders`       |
| **物流延迟率**         | `Late Delivery Rate` | 实际送达时间晚于承诺送达时间的订单占比                       | `SUM(is_late = 1) / COUNT(*)`        | `fct_orders`       |
| **平均提前天数**       | `Avg Advance Days`   | 所有已送达订单，实际送达比承诺送达平均提前的天数             | `AVG(-delay_days)`                   | `fct_orders`       |
| **晚到天数分桶**       | `Delay Bucket`       | 将延迟天数划分为 1-3天、4-7天、8-14天等区间，用于归因分析    | `CASE WHEN delay_days <= 3 THEN ...` | `fct_delay_review` |

## 3. 体验与质量域

| 指标名称           | 英文/代码字段      | 业务口径定义                                                | 计算公式                               | 数据源              |
| :----------------- | :----------------- | :---------------------------------------------------------- | :------------------------------------- | :------------------ |
| **平均满意度评分** | `Avg Review Score` | 统计周期内，有效订单的平均客户打分（1-5分）                 | `AVG(review_score_avg)`                | `v_orders_enriched` |
| **1星差评率**      | `1-Star Rate`      | 评价为1星的订单占已评价订单的比例（用于监控供应链质量风险） | `SUM(review_score_avg = 1) / COUNT(*)` | `v_orders_enriched` |
